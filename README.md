# vibe_coding1
# 今晚你是哪一攤？夜市小吃人格測驗

一個 10 題、約 2 分鐘可玩完的心理測驗網頁，測出你是 8 種夜市小吃中的哪一種：珍珠奶茶、雞排、臭豆腐、蚵仔煎、地瓜球、大腸包小腸、烤玉米、豆花。

風格為「深夜夜市霓虹招牌」，繁體中文、語氣輕鬆帶點台味。

## 線上試玩

（部署後貼上 GitHub Pages 網址）

## 功能

- 10 題選擇題，每題 4 個選項，可按「上一題」重答，也可用鍵盤數字 1–4 作答
- 8 種小吃角色，圖示全部以內嵌 SVG 繪製，並附小動畫
- 結果頁顯示稱號、性格描述、優點、小缺點、最速配、最不搭、金句，以及得分前 3 名的成分長條圖
- 音效與背景音樂以 Web Audio API 即時合成，不使用任何音檔，兩個開關可各自控制並會記住設定
- 分享功能：複製結果、下載結果卡（PNG）、LINE、Facebook、系統分享（手機）
- 分享連結 `?r=結果代碼` 可直接開啟對應結果頁，例如 `?r=chicken`
- 自適應版面（手機、平板、桌機），支援「減少動態效果」設定

## 計分規則

每個選項給一種小吃 +2 分（主分）、另一種 +1 分（副分）。答完 10 題後：

1. 最高分者為結果
2. 同分時，主分次數多者勝
3. 仍同分時，最後一次拿到主分較晚者勝

## 技術說明

- 單一 `index.html`，HTML、CSS、JavaScript 全部內嵌，不使用任何框架或套件
- 外部資源僅 Google Fonts（Huninn、Noto Sans TC）
- 圖像與聲音皆由程式產生，沒有版權問題
- 檔案大小約 63 KB

## 本機執行

直接雙擊 `index.html` 即可開啟。分享連結與 Facebook 分享需要部署到線上才會生效。

## 部署到 GitHub Pages

1. 把 `index.html` 放在 repository 根目錄
2. 到 repository 的 Settings → Pages
3. Source 選擇 `Deploy from a branch`，Branch 選 `main`，資料夾選 `/ (root)`，按 Save
4. 等待約一分鐘，即可用 `https://帳號.github.io/repository名稱/` 開啟

## 開發方式

本專案以 vibe coding 方式，依照「夜市小吃心理測驗｜網頁規格書」由 Claude Code 產出，為課堂作業。
